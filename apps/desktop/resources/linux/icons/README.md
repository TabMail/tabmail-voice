# Linux launcher icons

These are size variants of the shared `resources/icon.png`, generated by electron-builder’s bundled icon tool (`app-builder-lib/out/toolsets/icons.js`, `runIconsTool`, output format `set`). No new artwork.

Linux packaging uses this directory because supplying the single 1024px PNG installs only a 1024x1024 hicolor entry. Ubuntu’s icon-theme lookup does not discover that size, so the dock shows a generic icon even with correct desktop identity. Keep the 16–512px variants when refreshing the shared source icon.

Reference: https://www.electron.build/v26/docs/linux/#icon-configuration
