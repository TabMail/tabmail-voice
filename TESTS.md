# TabMail Voice — Tests

## `apps/desktop/` (ADR-DESK-032)

Run from `apps/desktop/`: `npm test` (Vitest), `npm run typecheck`, `npm run lint` (zero warnings),
and `./scripts/swift-errors.sh test` for the macOS helpers. `npm run preview` renders the overlay,
Settings and welcome windows with sample states and saves PNGs, to check the UI without starting the app; a page that logs an error, renders nothing or cuts off its buttons fails the run. No test touches the
network, the clipboard, the Keychain or the real Globe setting. Rows that name a Swift suite
(`DictationControllerTests` and others) mean the retired Swift app's, whose source and tests are in
git history (the parent of the commit that removed `apps/macos/`).
