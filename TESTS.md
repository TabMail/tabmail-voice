# TabMail Voice — Tests

## `apps/desktop/` (ADR-DESK-032)

Run from `apps/desktop/`: `npm test` (Vitest), `npm run typecheck`, `npm run lint` (zero warnings),
and `./scripts/swift-errors.sh test` for the macOS helpers. `npm run preview` renders the overlay,
Settings and welcome windows with sample states and saves PNGs, to check the UI without starting the app; a page that logs an error, renders nothing or cuts off its buttons fails the run. No test touches the
network, the clipboard, the Keychain or the real Globe setting. Rows that name a Swift suite
(`DictationControllerTests` and others) mean the retired Swift app's, whose source and tests are in
git history (the parent of the commit that removed `apps/macos/`).

`npm run test:placement` exercises a real Electron surface and renderer at all four display
corners using synthetic state, without the app's helpers, sign-in or network. It compares pill and
every tool bubble's screen coordinates before and after chat opens, checks chat's horizontal inset,
and proves tip toggles leave chat, pill and bubbles unchanged. Screenshots and `geometry.json` go to
`/tmp/voice-placement-smoke` (or pass an output directory). The original faulty placement was tested
RED first: opening chat at the top-right shifted the pill and every tool 20 points horizontally
and 107 points vertically. The identical test then passed all four corners on the fix. A native
surface can constrain `setBounds`; a mock accepting requested bounds is insufficient for this check.
